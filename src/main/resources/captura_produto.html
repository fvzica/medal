Captura de Produto GOL → Config

Cole os subscribe: de um produto e gere a configuração pronta

Como capturar (30 segundos por produto)

  1. Abra a página do produto no GOL (ex.: .../9007/credito-pf/relacionamento/total/jurisdicao).
  2. Abra o DevTools (F12) → aba Network → filtro Socket (WS) → recarregue (F5).
  3. Clique na conexão live → aba Messages.
  4. Selecione e copie todas as linhas subscribe:... (as de seta ↑).
  5. Cole abaixo, dê o nome do produto e clique em Gerar config.

Dica: pode colar linhas extras (handshake, dados) que eu ignoro — só uso os subscribe:.
